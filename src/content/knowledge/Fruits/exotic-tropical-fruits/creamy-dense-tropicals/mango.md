## Overview

*Scientific name: Mangifera indica*

Mango is a tropical stone fruit providing about 60 kcal per 100 g, rich in vitamin C and provitamin-A carotenoids, with a low-to-medium glycemic index — best eaten in controlled portions when managing blood sugar.

**Typical serving:** Typical serving ~150 g (about half a medium mango).

## Nutrition composition (per 100 g)

| Nutrient | Amount |
| :--- | ---: |
| Energy | 60 kcal |
| Water | 83.5 g |
| Carbohydrate | 14.98 g |
| Sugars | 13.66 g |
| Fiber | 1.6 g |
| Protein | 0.82 g |
| Fat | 0.38 g |
| Vitamin C | 36.4 mg |
| Vitamin A (RAE) | 54 µg |
| Folate | 43 µg |
| Potassium | 168 mg |

**Glycemic index:** 51 — Low–medium GI (~51); glycemic load rises with portion because sugar content is high.

**Key nutrients:** Vitamin C, Provitamin A (beta-carotene), Folate, Potassium

**Seasonality (India):** Summer (Mar–Jul)

## What the evidence says

- **[Strong evidence]** A useful dietary source of vitamin C and provitamin-A carotenoids.
- **[Limited evidence]** Portion-controlled mango can fit a diabetes-appropriate diet; its moderate GI means glycemic load depends on quantity. *(study citation under clinical review)*

## Preparation intelligence

Vitamin C degrades with prolonged heat; eat fresh to retain it.
