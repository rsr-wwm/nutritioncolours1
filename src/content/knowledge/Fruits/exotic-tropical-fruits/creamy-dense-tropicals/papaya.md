## Overview

*Scientific name: Carica papaya*

Papaya is a low-calorie tropical fruit (~43 kcal per 100 g) rich in vitamin C, provitamin-A carotenoids, and the enzyme papain.


## Nutrition composition (per 100 g)

| Nutrient | Amount |
| :--- | ---: |
| Energy | 43 kcal |
| Water | 88.1 g |
| Carbohydrate | 10.8 g |
| Sugars | 7.8 g |
| Fiber | 1.7 g |
| Protein | 0.47 g |
| Fat | 0.26 g |
| Vitamin C | 60.9 mg |
| Vitamin A (RAE) | 47 µg |
| Folate | 37 µg |
| Potassium | 182 mg |

**Glycemic index:** 60 — Medium GI.

**Key nutrients:** Vitamin C, Provitamin A, Folate, Papain

**Seasonality (India):** Year-round

## What the evidence says

- **[Moderate evidence]** Low energy density with high vitamin C makes it a useful choice in weight-aware diets.
